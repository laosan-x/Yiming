# 壹鸣 WonderLand · 打赏引导方案（SPONSORSHIP）

> 目标：让愿意支持的用户**顺其自然地**找到打赏入口并完成支持，同时保证**零打扰**——
> 任何场景下都不弹窗、不阻断、不与功能绑定。原则一句话：**价值先行，入口随取，分文不欠。**

---

## 一、渠道调研与组合建议

### 1.1 渠道对比（费率与可用性，2026-11 核实）

| 渠道 | 平台费率 | 国内创作者可收款 | 支付方式 | 适合场景 |
|---|---|---|---|---|
| **微信 / 支付宝收款码** | **0%** | ✅ | 微信 / 支付宝 | 国内一次性打赏，最直接 |
| **爱发电**（afdian.com） | **6%**（1% 支付通道 + 5% 平台），创作者得 94% | ✅（国内手机注册，境外邮箱可绕过） | 微信 / 支付宝 | 国内**月度赞助**、档位运营 |
| **Ko-fi** | 一次性小费 **0%**（免费档）；会员/商店 5%；Gold $12/月全免 | ⚠️ 需 PayPal（大陆可跨境收款） | PayPal / 卡 / Apple Pay | 国际小额打赏首选 |
| **Buy Me a Coffee** | 全类型 **5%** 固定 | ❌ 提现仅限 Stripe 支持国，大陆不可 | 卡 | 不推荐（大陆无法提现） |
| **GitHub Sponsors** | **0%** | ❌ **不支持中国大陆**（支持列表仅含港澳台） | 卡 | 大陆作者暂不可用；未来若开放优先接入 |
| **PayPal 直收** | ~2.9% + $0.30 | ✅（跨境提现） | PayPal | 国际直付，无平台审核 |
| **加密货币** | 仅链上 Gas | ✅ | BTC/ETH 钱包 | 极客受众的补充选项 |
| Liberapay / Open Collective | 0% / 平台分账 | ⚠️ 提现链路绕 | 卡 | 可作远期备选 |

### 1.2 组合建议（本项目采用）

```
国内用户 ──► ① 微信/支付宝收款码（默认展示，0% 直达）
              ② 爱发电（月度赞助，可持续性最好）
国际用户 ──► ③ Ko-fi（小费 0%，PayPal 收款，卡/Apple Pay 通吃）
长期位  ──► ④ GitHub Sponsors（政策开放后第一个接入）+ FUNDING.yml 占位
```

决策依据：
- **收款码是转化率最高的国内通道**（扫码 3 秒完成，0 手续费），保留为默认主展示
- **爱发电补足「可持续性」**——收款码是一次性的，爱发电的月度档位让支持变成持续收入，
  且有公开账目，比二维码更「优雅」（爱发电官方 FAQ 原话）
- **Ko-fi 是国际侧的最优解**：一次性小费 0% 平台费 + 直接进自己 PayPal（资金不过平台），
  比 BMC（5% 固定 + 大陆无法提现）与 Patreon（8–12%）友好得多
- **GitHub Sponsors 暂时只能占位**：`.github/FUNDING.yml` 先配置 `ko-fi` / 其他可用项，
  大陆收款一旦开放即刻切换

## 二、入口设计（结合现有界面）

| 位置 | 形式 | 触发方式 | 状态 |
|---|---|---|---|
| **标题栏右侧 ☕** | 纯图标按钮（黑白灰，悬停浅灰底） | 用户主动点击 → 右缘停靠浮层 | ✅ 已实现 |
| **打赏浮层** | 停靠式面板：说明文案 + 双收款码 + 金额建议 + 渠道链接 | 仅由 ☕ 唤起，点外部关闭 | ✅ 已实现 |
| **关于页「鸣谢」尾部** | 一行温和文字指向 ☕ 入口 | 纯静态，无弹窗 | ✅ 已实现 |
| **README / FUNDING.yml** | `FUNDING.yml` 配置 + README 尾部赞助章节 | GitHub 侧「♡ Sponsor」按钮 | 🔜 P1（开源发布时） |
| **首次启动引导** | 不做打赏引导（只做功能引导） | — | ❌ 刻意排除 |
| 使用时长/次数触发提醒 | 不做 | — | ❌ 刻意排除 |

**设计红线**（保证「不产生反感」）：
1. **永不主动弹出**打赏界面——入口只存在于用户主动可发现的位置
2. **不与功能绑定**——打赏不解锁任何东西，也不暗示「不打赏功能会少」
3. **不比较、不施压**——不放「本月只收到 ¥xx」之类的道德压力文案
4. **视觉降噪**——入口是黑白灰纯图标，不用跳色、不闪烁、不加红点

## 三、引导策略（提升意愿的正确姿势）

1. **先给足价值，再给出口**：文案围绕「免费 · 无广告 · 本地隐私」三件套展开——
   用户认同价值才有意愿，话术永远落在「支持持续开发」而非「救济作者」
2. **心理账户小额化**：建议金额从 ¥6.6 起（一杯奶茶价），金额文案强调「随心就好」，
   并明示「0 元的 Star 也是很好的支持」——降低心理门槛反而提高转化
3. **透明承诺**：浮层固定脚注「打赏不升级、不解锁、不影响任何功能」，杜绝「骗钱」疑虑
4. **贡献者鸣谢**：关于页「鸣谢」章节同时感谢上游模型作者与支持者（后续可加
   「感谢本月 12 位支持者」滚动条，数据由爱发电 API 拉取，P2 再做）
5. **里程碑目标**（P2）：浮层内可选展示「目标：¥xxxx / 覆盖模型托管费用」，进度条式、
   可配置、默认关闭——给捐赠一个具体的用途叙事
6. **多语言**：全部文案走 i18n 双语表，渠道 label 由配置文件自带（可写任意语言）

## 四、技术实现

### 4.1 配置化（已完成）

**收款码**：`content/sponsor/{wechat,alipay}.png`
- 加载顺序：exe 同目录 → 工作目录 → 编译期内嵌占位图；替换图片重启即生效

**打赏配置**：`content/sponsor/links.json`（对象结构，全部字段可选）

```json
{
  "star_url": "https://github.com/你的用户名/仓库",
  "channels": [
    { "label": "爱发电 · 月度赞助", "icon": "zap",    "url": "https://afdian.com/a/你的ID" },
    { "label": "Ko-fi · 国际打赏",  "icon": "coffee", "url": "https://ko-fi.com/你的ID" }
  ],
  "goal": {
    "enabled": false,
    "label": "覆盖模型托管与构建服务费用",
    "target": 500,
    "current": 0
  }
}
```

- `channels[].label`：展示文案，任意语言（不走 i18n 表，由发布者自定）
- `channels[].icon`：`icons.rs` 表内名称（`zap`/`coffee`/`star`/`globe`…），未知名称回退问号圈，不崩溃
- `star_url`：「0 元的 Star 也是很好的支持」入口；缺省则该行整行隐藏
- `goal`：里程碑目标进度条（**enabled 默认 false → 整区不渲染**）；`label` 为用途叙事可任意语言，`current/target` 驱动进度
- **channels 为空 / 文件解析失败 → 各可选区自动隐藏**（优雅降级，永不出错样）
- 加载顺序：exe 同目录 → 工作目录 → 内嵌默认；`OnceLock` 缓存，修改后重启生效

**发布前必改清单**：
- [ ] `content/sponsor/{wechat,alipay}.png` 换成真实收款码
- [ ] `content/sponsor/links.json` 填入真实渠道 URL（爱发电 ID / Ko-fi ID / 仓库地址）
- [ ] `.github/FUNDING.yml`（开源发布时）
