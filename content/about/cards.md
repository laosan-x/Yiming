## 工具介绍

壹鸣 是一个**本地优先**的商品图与人像处理工作台：所有推理都在本机完成，图片不上传、不依赖云端服务。它把「抠图 → 精修 → 导出」收进一个界面，用神经网络与传统算法分工 —— 小模型走 CPU 秒级出图，大模型自动调度到独立显卡。

**核心功能**

- SmartMatte v2 经典抠图：纯色 / 白底商品图毫秒级出干净蒙版
- 神经网络抠图：MODNet 人像发丝级边缘，插件目录可扩展任意 .onnx 模型
- 保留 / 擦除画笔与吸管取样：复杂背景手工精修
- 证件照模式：7 种官方底色 + 35 种规格排版，直出打印排版
- 计算后端自动分配：小模型走 CPU、大模型走独显（DirectML），支持手动覆盖

**典型使用场景**

- 电商主图 / 详情页：白底商品图快速去背景，一键导出 800~2048px 平台规格
- 证件照制作：换底色、裁切规格、冲印排版
- 人像 / 毛绒 / 硬边金属等复杂材质：神经网络模型 + 画笔精修
- 离线环境：全程本地推理，无网络也能完成全部处理

## 处理流程

1. **背景取样** —— 四角中位数 / 仅左上角 / 自定义取色
2. **连通域分割** —— 颜色接近且非轮廓的区域才判定为背景
3. **形态学** —— 收缩 / 扩张，修复边缘缺口
4. **羽化与去色晕** —— 消除白边、紫边等背景残留
5. **手工精修** —— 保留 / 擦除画笔 + 吸管取样

## 快捷键

`Q` 智能抠图（自动）

`B` 保留画笔

`E` 擦除画笔

`I` 吸管取样

`]` `[` 画笔变大 / 变小

`0` 适应窗口

`Ctrl` `S` 导出
